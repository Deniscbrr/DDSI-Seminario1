Memoria del Seminario 1 - Acceso a Bases de Datos (ODBC)Asignatura: Diseño y Desarrollo de Sistemas de Información (DDSI)

1. Lenguaje utilizado y tecnología de acceso:
El proyecto ha sido desarrollado íntegramente en el lenguaje C++. Para la comunicación con el Sistema Gestor de Bases de Datos (SGBD) Oracle, se ha empleado la API estándar nativa ODBC (Open DataBase Connectivity), haciendo uso de las librerías del sistema <sql.h> y <sqlext.h>.

2. Entorno de conexión y configuración:
La aplicación cliente se conecta al servidor de la Universidad de Granada. Los parámetros de red configurados en la cadena de conexión son los siguientes:

Host: oracle0.ugr.es

Puerto: 1521

Servicio (DBQ): practbd
Para garantizar el acceso seguro desde el exterior de la red del campus, la ejecución de la aplicación requiere tener activa la conexión VPN de la UGR. El entorno de ejecución gestiona la memoria de los manejadores ODBC (SQLHENV, SQLHDBC y SQLHSTMT) de forma segura.
